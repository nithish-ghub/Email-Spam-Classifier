# Email Spam Classifier

A Machine Learning based Email Spam Classifier that detects whether a message/email is spam or ham using Natural Language Processing (NLP) and supervised learning algorithms.

## Features

- Detects spam and legitimate messages
- Uses TF-IDF Vectorization
- Trained using Multinomial Naive Bayes
- Real-time prediction through Python console
- High accuracy spam classification

## Technologies Used

- Python
- pandas
- NumPy
- scikit-learn
- NLTK
- joblib
